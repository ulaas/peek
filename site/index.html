Remote desktop, quietly.

Peek is a fast RDP and VNC client written in Rust. Its interface stays dim and out of the way, so the computer you connect to is the brightest thing on your screen.

Type a name, get a desktop

Enter a host name, an address or a URL and press Enter. server01 opens RDP, vnc://pi.local:1 opens VNC on display 1, and alice@10.0.0.5:3390 brings a user name and a port along.

Already use the Windows Remote Desktop app? Drop its .rdp files on Peek and they become saved connections.

Everything is one shortcut away

Press Ctrl K and start typing: saved connections and every action are in one list. Type an address that isn't saved yet and the first entry connects to it.

The library keeps groups, favorites and recents, and can wake a sleeping computer with Wake-on-LAN. Passwords go in your operating system's keychain, not in a file next to the app.

The session gets the screen

Each computer opens in its own tab, and the home screen shows live thumbnails of every open session. A small toolbar floats over the remote picture and stays out of the way.

On Windows, the Windows key, Alt+Tab and Print Screen go to the remote computer. Ctrl Alt Enter toggles full screen. If the connection drops, Peek reconnects on its own.

Sound and clipboard, both ways

Remote audio plays through Peek's own low-latency pipeline, in your sound device's native format. Every session has its own volume and mute, and a speaker on the tab shows which one is playing.

Copy text or whole files on one computer and paste them on the other.

Record a session, play it back

Recordings keep a lossless picture and Opus sound in a single .peekrec file. Open one in the built-in player to scrub through it, or export an MP4 (H.264 and AAC) to share.

Two protocols, written with care

Peek speaks RDP first and VNC second. Both draw into the same framebuffer, which tracks the regions that changed, so only new pixels are copied to the screen.

RDP

Built on IronRDP, for Windows computers and servers.

  • TLS and Network Level Authentication (CredSSP)
  • RemoteFX, with the remote screen resizing to match the window
  • Text and file clipboard in both directions
  • Opus or PCM audio with remote volume
  • Certificates trusted on first use, then checked every time
  • Local, domain and Microsoft account sign-in

VNC

Peek's own RFB 3.3 to 3.8 client, for Linux desktops, Raspberry Pis and Macs.

  • No authentication or VNC password
  • Raw, CopyRect, RRE, Hextile, ZRLE and Tight with JPEG
  • Bounds and size checks on every rectangle a server sends
  • Tested end to end against a bundled test server
  • Randomized robustness tests for the decoders

Not there yet

SSH, Remote Desktop Gateway, H.264 for RDP (EGFX) and keyboard grab on macOS and Linux are still to come. Follow along or help out on GitHub.

Download

Version 0.5.0. Pick the installer for your system, or a portable build that runs without installing.

  • Windows

    Windows 10 and 11, x64. The installer adds Peek to the Start menu and the command line, and opens recordings.

    Installer (.msi) Portable .zip

    Peek isn't code-signed yet, so SmartScreen may warn the first time. Choose More info, then Run anyway.

  • Linux

    x64 with glibc 2.39 or newer, such as Ubuntu 24.04, Debian 13 or Fedora 40. X11 and Wayland.

    Debian, Ubuntu (.deb) Fedora, openSUSE (.rpm) Portable .tar.gz

    Open the package with your software center, or install it with apt or dnf. From the portable archive, run ./install.sh.

  • macOS Preview

    macOS 11 or newer on Apple silicon. Open the disk image and drag Peek to Applications.

    Disk image (.dmg) Portable .zip

    Not yet tested on a Mac, and not notarized. On first launch, open System Settings, then Privacy & Security, and choose Open Anyway.

Or build it yourself

You need Rust 1.90 or newer and CMake. On Linux, also the ALSA headers (libasound2-dev). Peek is a Cargo workspace of small crates; the default member is the app.

  1. Get the code

    git clone https://github.com/ulaas/peek
cd peek

  2. Build and run

    cargo run --release

  3. Try VNC without a second computer

    cargo run -p peek-vnc --example testserver -- 5999
peek vnc://127.0.0.1:5999
